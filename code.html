Merging Indonesia's PODES Waves

PODES Merge (GitHub) · DOI: 10.5281/zenodo.24172713

This repository contains crosswalks and Stata do-files that merge villages across the Indonesian village census (PODES) waves of 2005, 2008, 2011, 2014, 2018, 2019, 2020, 2021, 2024, and 2025. The do-files also merge PODES with the village population counts from the 2010 population census and link BPS village codes to the Ministry of Home Affairs (Kemendagri) codes used in Dana Desa and village population data. Users who need only village codes and names across years can use the prebuilt files in the repository without purchasing PODES data. See the README for details.

If you use this code in your own work, please cite the following paper:

Cassidy, Traviss, Nurina Merdikawati, and Tejaswi Velayudhan. 2026. "Decentralization and Development: Evidence from Indonesia's Village Law." Working paper.

PODES 1993–2014 Merge

This folder contains crosswalks and Stata do-files that merge villages across the Indonesian village census (PODES) waves of 1993, 1996, 2000, 2003, 2005, 2008, 2011, and 2014. The do-files also merge PODES with the village population counts from the 2010 population census. The folder also includes crosswalks spanning 2013–2021 for users who wish to merge PODES 2014 with PODES 2018–2021.

If you use this code in your own work, please cite the following paper:

Cassidy, Traviss. 2025. "Revenue Persistence and Public Service Delivery." Economic Journal, 135 (670): 2017–2053.

For details on the merge procedure, see the Data Appendix in the paper cited above.
