Indonesian District GDP, 1993–2013

Indonesian District GDP, 1993–2013

This folder contains a panel of district-level (kabupaten/kota) GDP for Indonesia, along with the raw data and Stata code used to construct it. The panel includes nominal and real GDP for 1993–2013, both in total and excluding oil and gas. It also includes nominal GDP for 1983–1992. However, these data suffer from quality issues, as noted in the README file. All series are aggregated to 1993 district borders. For details on the data sources and construction methodology, see the README file in the folder.

If you use these data in your own work, please cite the following paper:

Brehm, Margaret E., Paul A. Brehm, Alecia Cassidy, and Traviss Cassidy (2026): “Resource Booms, Revenue Sharing, and Growth,” Journal of Development Economics, 182: 103811, 2026.
